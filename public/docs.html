Media Server API Documentation

Movies API

Base Endpoint: /movies

Available Methods:

GET /movies

Retrieves all movies

Response: Array of movie objects

[
    {
        "id": 1,
        "title": "Movie Title",
        "genre": "Action",
        "releaseYear": 2023,
        "director": "Director Name",
        "duration": "120 minutes",
        "rating": "PG-13",
        "mediaFile": "filename.mp4",
        "thumbnail": "thumbnail.jpg"
    }
]
POST /movies

Adds a new movie

Request Body Format:

{
    "id": number,
    "title": string,
    "genre": string,
    "releaseYear": number,
    "director": string,
    "duration": string,
    "rating": string,
    "mediaFile": {
        "name": string,
        "data": binary
    },
    "thumbnail": {
        "name": string,
        "data": binary
    }
}
PUT /movies?id=:id

Updates an existing movie

Request Body Format: Same as POST

DELETE /movies?id=:id

Deletes a movie

Response: Updated array of movies

Media Downloads

GET /download/:filename

Downloads the specified media file

Parameters:

filename: string (The name of the file to download)

Response: Binary file data with appropriate content type

Error Responses

{
    "error": "Error message",
    "status": 404/400/500
}

Common Status Codes:

  • 200: Success
  • 400: Bad Request
  • 404: Not Found
  • 500: Internal Server Error
